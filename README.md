# 🌾 Rice Classification Using PyTorch | 99.05% Test Accuracy

I'm excited to share my **Rice Classification using Deep Learning with PyTorch** project! 🚀

In this project, I developed a binary classification neural network to classify rice samples into two classes using 10 numerical features extracted from rice grain measurements.

### 🔍 Project Overview
The model uses the following features:
- Area
- MajorAxisLength
- MinorAxisLength
- Eccentricity
- ConvexArea
- EquivDiameter
- Extent
- Perimeter
- Roundness
- AspectRation

### 🧠 Model & Technologies
- **Framework:** PyTorch
- **Model:** Feedforward Neural Network
- **Architecture:** 10 → 32 → 16 → 1
- **Activation Functions:** ReLU and Sigmoid
- **Optimizer:** Adam
- **Loss Function:** Binary Cross-Entropy
- **Preprocessing:** StandardScaler
- **Training:** 50 epochs
- **Data Split:** 70% Training, 15% Validation, 15% Testing

### 📊 Model Performance
- ✅ **Test Accuracy:** 99.05%
- ✅ **Test Loss:** 0.0282
- ✅ **Test Samples:** 2,728
- ✅ **Class 0 Correct Predictions:** 1,215 / 1,230
- ✅ **Class 1 Correct Predictions:** 1,487 / 1,498

The model achieved strong performance on the test dataset, demonstrating the potential of neural networks for rice classification using numerical grain characteristics.
